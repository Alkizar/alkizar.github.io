DoubleTT and categorical logic

CatColab is a collaborative modelling platform based on categorical logic.

DoubleTT is an extension of CatColab which facilitates model composition using a type theory for models of double theories.

The theory for a particular logic defines the “shape” of models in the corresponding doctrine. Formally:

  • a theory is a fibrational VDC (possibly unital, possibly with loose composites) equipped with zero or more double monads, called modalities.
  • a model \(M\) of a theory \(\mathbb{T}\) is a restriction-preserving functor \[M : \mathbb{T} \to \mathbb{S}\mathrm{pan}\].

Specifying custom theories

Currently the theories available in DoubleTT are a small handful of static, hard-coded options.

Goal: allow the user to define their favorite theory by

  1. specifying a signature (generators)
  1. specifying axioms (relations)
  1. with a guarantee that the resulting theory is always correct by construction.

Specifying custom theories

Idea: annotate the user-specified theory with types, such that a theory which successfully typechecks is always valid.


Observation: user-defined axioms can equate any pair of cells with the same boundary, so this amounts to a type theory for the internal language of VDCs.


Remark: as we saw for the theory of promonads, theories may also equate (pro)arrows, so even checking compatibility of cell boundaries is nontrivial.

An internal logic of VDCs

Hayato Nasu’s past work on a type theory for (fibrational, cartesian) VDCs guided the early stages of this project.

Idea: describe a pointful syntax for the constructs in a VDC, which reduces equivalent (via universal property) structures to a single normal form.


Here “pointful” means we refer to terms in the type theory with functions applied to arguments, in contrast to the “point-free” morphism notation we are familiar with in category theory:

Example: given morphisms \(f : X \times Y \to U,\) \(g : X \to V\), and \(h : U \times V \to Z,\) we can construct a map \(X \times Y \to Z\) which is written in both styles below:

Point-free: \(h \circ (f \times g) \circ (1_X \times \sigma_{X, Y}) \circ (\Delta_X \times 1_Y)\)

Pointful: \(x : X, y : Y \vdash h(f(x, y), g(x))\)

An internal logic of VDCs

The correspondence between constructs in a VDC and the syntax of Nasu’s type theory is outlined below:

Product Context \(\prod_{i=1}^n X_i \Leftrightarrow x_1 : X_1, \dots, x_n : X_n \text{ ctx}\)

Restrictions

For this type theory to model the internal language of fibrational VDCs it needs to capture restriction cells and their universal property.

Given a proarrow \(P : Y_0 \nrightarrow Y_1\) and tight morphisms \(f_i : X_i \to Y_i\), the protype \[ x_0 : X_0 ; x_1 : X_1 \vdash P(f_0(x_0); f_1(x_1)) \] represents the restriction of \(P\) along \(f_0\) and \(f_1\).

An internal logic of VDCs

Restrictions

We recover the corresponding restriction cell

with the proterm \[ x_0 : X_0, x_1 : X_1 \vert p : P(f_0(x_0); f_1(x_1)) \vdash p : P(f_0(x_0), f_1(x_1)), \] since the tight identity cell of a restriction proarrow corresponds uniquely with the restriction cell via the universal property.

An internal logic of VDCs

(Loose) Units/Composition

The type theory can be extended with type formation, introduction, and elimination rules for loose units and loose composites.

Like restriction, we encode the universal properties of these constructs using a normal form. Namely, the \(\beta\)/\(\eta\)-reduction rules for units and composites precisely capture their universal properties.

An internal logic of VDCs

Shortcomings

Nasu’s type theory offers a strong foundation, but it lacks some important characteristics that are important to our use case:

  1. Inflexible signature: generator cells cannot map into a restriction or unit proarrow, for instance.
  1. Missing modalities: virtual double monads are not supported by the type theory, which are essential for defining many important doctrines.
  1. Challenging to implement: the type theory is not designed with algorithmic typechecking in mind.

ModalTT

Type Theory

To address the problems outlined above, we have adapted Nasu’s type theory in a number of ways:

  1. Our signatures stratify VDC constructs into different syntactic categories to get a more expressive range of legal generators.
  1. We introduce first class modality application into the syntax, without compromising the normal forms of (pro)terms.
  1. Our type theory uses an ordered linear logic to describe the resource-sensitivity and order-sensitivity of proterms. Loose composition reduces to the fuse operator.

ModalTT

DSL for theory specification

Users specify the generators (objects, tight/loose arrows, and cells) of their theory:

Objects

obj X
obj [Y, Z]

Arrows and proarrows

fun f : X -> Y
pro P : X => Y

Cells

cell α : [P, Q] => (List R) | f -> id Y

ModalTT

DSL for theory specification

Users can declare equalities of proarrows and of proterms (virtual cells), which define the axioms of the theory:

Proarrow Axioms

pro_axiom P := P * P

Proterm Axioms (this is where the magic happens)

-- Promonad axioms
axiom [x0 : X, x1 : X] | [p : P[x0, x1]] |- θ (x0) * p := p
axiom [x0 : X, x1 : X] | [p : P[x0, x1]] |- p := p * θ (x1)
-- Can apply the list monad or use its (primitive) structure proterms
axiom [x : X, y : Y] | [p : (List P)[x, y]] |- μ List [(List (η List P)) [p]] := p 
-- Loose composites are destructured via let binding (more on this soon)
axiom [x0 : X, x1 : X] | [...] |- 
  let ([p : P[x0, x1], q : Q[x1, x2]] = α [...] * β [...]) in γ[p, q] := ...

ModalTT

Type theory

We adapt Nasu’s type theory by introducing modalities and broadening the expressive power of the generator symbols.

To match the implementation, we also rely less heavily on substitution (which is badly behaved in the presence of non-syntactic equalities.)

ModalTT

Signature: Generators

The signature \(\Sigma\) determines the structures of a theory \(\mathbb{T}_\Sigma\):

  • \(\mathcal{T}_\Sigma\) is the set of object generator symbols.
  • \(\mathcal{F}_\Sigma(X, Y)\) is the set of arrow generator symbols from \(X\) to \(Y\) (\(X\) and \(Y\) are object symbols).
  • \(\mathcal{P}_\Sigma(X, Y)\) is the set of proarrow generator symbols from \(X\) to \(Y\) (\(X\) and \(Y\) are object symbols).
  • \(\mathcal{C}_\Sigma(P_1, \dots, P_n \Rightarrow Q | f \to g)\) is the set of cell generator symbols (\(P_i, Q\) are proarrow symbols and \(f, g\) are arrow symbols).
  • \(\mathcal{M}_\Sigma\) is the set of modality symbols.

ModalTT

Signature: Modal Closure

  • To form the set of object symbols \(\widetilde{\mathcal{T}}_\Sigma\), we take the closure of \(\mathcal{T}_\Sigma\) under the application of each modality symbol in \(\mathcal{M}_\Sigma.\)
  • The set of basic arrow symbols \(\widetilde{\mathcal{F}}_\Sigma\) are obtained by taking the closure of \(\mathcal{F}_\Sigma\), along with the structure maps \(\eta^L\) and \(\mu^L\) of each monad symbol \(L \in \mathcal{M}_\Sigma\), under modal application.
  • The set of basic proarrow symbols is defined similarly, excluding the monad structure maps.

ModalTT

Signature: Complete Closure

  • The full set of arrow symbols \(\hat{\mathcal{F}}_\Sigma\) is obtained by closing \(\widetilde{\mathcal{F}}_\Sigma\) under tight identities and composition.
  • The full set of proarrow symbols is generated analogously (except with loose units and loose composition).
  • The set of cell symbols \(\widetilde{\mathcal{C}}_\Sigma(P_1, \dots, P_n \Rightarrow Q \vert f \to g)\) is the closure of \(\mathcal{C}_\Sigma\), together with the structure cells \(\eta^L\) and \(\mu^L\) for each monad symbol \(L \in \mathcal{M}_\Sigma\), under modal application.

ModalTT

Signature: Extended Modal Application

Only the basic arrow/proarrow symbols are allowed to support direct, syntactic modal application.

The application of a modality can be extended to the complete sets of arrows/proarrows by structural recursion. (The fact that each modality is expected to commute with all available structures is crucial here.)

For instance, on arrow symbols we define \[ L[f] := \begin{cases} Lf & \text{ if } f \in \widetilde{\mathcal{F}}_\Sigma\\ L[h] \circ L[g] & \text{ if } f = h \circ g\\ \mathrm{id}_{LX} & \text{ if } f = \mathrm{id}_X \end{cases} \]


Note: this extension is a derived form (i.e. “syntactic sugar”). It does not introduce any new symbols into the grammar.

ModalTT

Typing Judgments

\[ \begin{aligned} \text{Type} & ::= X \text{ type}\\ \text{Context} & ::= \Gamma \text{ ctx}\\ \text{Term} & ::= \Gamma \vdash s : X\\ \text{Protype} & ::= \Gamma_0 ; \Gamma_1 \vdash P \text{ protype}\\ \text{Procontext} & ::= \Gamma_0 , \dots , \Gamma_n \vert \Omega \text{ proctx}\\ \text{Proterm} & ::= \Gamma_0, \dots, \Gamma_n \vert \Omega \vdash \mu : P \end{aligned} \]

Terms: Typing Judgments


\inferrule*
  {\strut}
  {x : X \vdash x : X}


\inferrule*
  {f \in \widetilde{\mathcal{F}}_\Sigma(X, Y) \\ \Gamma \vdash s : X}
  {\Gamma \vdash f(s) : Y}

ModalTT

Terms: Arrow Application

Note that the typing judgements for terms only describe the application \(f(s)\) of a basic arrow \(f\).


As with modal applications, we can extend basic arrow application to all arrows as a derived form:

\[ f [\![s]\!] := \begin{cases} f(s) & \text{if } f \in \widetilde{\mathcal{F}}_\Sigma\\ h(g(s)) & \text{if } f = h \circ g\\ s & \text{if } f = \mathrm{id}_X \end{cases} \]

ModalTT

Terms: Substitution

Terms are equipped with a meta-theoretic variable substitution, defined in the obvious way:

\[ t[s/x] := \begin{cases} s & \text{if } t = x\\ f(t'[s/x]) & \text{if } t = f(t') \end{cases} \]

(As usual, we assume that \(x\) is not a variable in \(s\) to avoid variable capture.)

Protypes: Grammar

\[ \begin{aligned} s_0, s_1 & \in \mathrm{Term}\\ P & \in \hat{\mathcal{P}}_\Sigma\\ \underline{P} &\in \mathrm{Protype} ::= P(s_0, s_1) \end{aligned} \]

ModalTT

Protypes: Typing Judgments


\inferrule*
  {P \in \widetilde{\mathcal{P}}_\Sigma(X, Y) \\ \Gamma_0 \vdash s_0 : X \\ \Gamma_1 \vdash s_1 : Y}
  {\Gamma_0 ; \Gamma_1 \vdash P(s_0, s_1) \text{ protype}}


\inferrule*
  {\Gamma_0 \vdash s_0 : X \\ \Gamma_1 \vdash s_1 : X}
  {\Gamma_0 ; \Gamma_1 \vdash \mathrm{unit}_X(s_0, s_1) \text{ protype}}


\inferrule*
  {\Gamma_0 ; \Gamma_1 \vdash P(s_0, s_1) \text{ protype} \\ \Gamma_1 ; \Gamma_2 \vdash Q(s_1, s_2) \text{ protype} }
  {\Gamma_0 ; \Gamma_2 \vdash (P \odot Q)(s_0, s_2) \text{ protype}}

Procontexts: Grammar

For \(n \geq 0\): \[ \begin{aligned} \Gamma_i &\in \mathrm{Context}\\ \underline{P_i} &\in \mathrm{Protype}\\ p_i &\in \mathrm{Var}_\mathrm{Proterm}\\ \overline{\Gamma} \vert \Omega &\in \mathrm{Procontext} ::= \Gamma_0, \dots, \Gamma_n \vert p_1 : \underline{P_1}, \dots, p_n : \underline{P_n} \end{aligned} \]


Note: both components of our procontexts are ordered (in the sense of ordered linear logic).

ModalTT

Procontexts: Typing Judgments


\inferrule*
  {\Gamma \text{ ctx}}
  {\Gamma \vert \cdot \text{ proctx}}


\inferrule*
  {\Gamma_0, \dots, \Gamma_n \vert p_1 : P_1(s_0, s_1), \dots, p_n : P_n(s_{n-1}, s_n) \text{ proctx} \\ \Gamma_n ; \Gamma_{n + 1} \vdash P_{n+1}(s_n, s_{n+1}) \text{ protype}}
  {\Gamma_0, \dots, \Gamma_{n+1} \vert p_1 : P_1(s_0, s_1), \dots, p_{n+1} : P_{n+1}(s_n, s_{n+1}) \text{ proctx}}

ModalTT

Proterms: Grammar

\[ \begin{aligned} p_i &\in \mathrm{Var}_\mathrm{Proterm}\\ f, g &\in \hat{\mathcal{F}}_\Sigma \\ s_i &\in \mathrm{Term} \\ \alpha &\in \hat{C}_\Sigma(P_1, \dots, P_n \Rightarrow Q \vert f \to g)\\ \mu &\in \mathrm{Proterm} \\ &::= p \\ &\hspace{0.5em}\vert \alpha \langle s_0, \dots, s_n \rangle (\mu_1, \dots, \mu_n) \\ &\hspace{0.5em}\vert \mu_1 \odot \mu_2\\ &\hspace{0.5em}\vert \text{let } [p_1 : \underline{P_1}, p_2 : \underline{P_2}] = \mu_1 \text{ in } \mu_2\\ \end{aligned} \]

ModalTT

Proterms: Typing Judgments


\inferrule*
  {\strut}
  {\overline{\Gamma} \vert p : \underline{P} \vdash p : \underline{P} }


\inferrule*
  {\overline{\Gamma}_i \vert \Omega_i \vdash \mu_i : P_i(s_{i-1}, s_i) \\ \alpha \in \widetilde{\mathcal{C}}_\Sigma(P_1, \dots, P_n \Rightarrow Q \vert f \to g) \\ i = 1, \dots, n}
  {\overline{\Gamma}_1, \dots, \overline{\Gamma}_n \vert \Omega_1, \dots, \Omega_n \vdash \alpha(s_0, \dots, s_n)\{\mu_1, \dots, \mu_n\} : Q(f [\![ s_0 ]\!], g [\![s_n]\!] )}


\inferrule*
  {\overline{\Gamma}_1 \vert \Omega_1 \vdash \mu_1 : P_1(s_0, s_1) \\ \overline{\Gamma}_2 \vert \Omega_2 \vdash \mu_2 : P_2(s_1, s_2)}
  {\overline{\Gamma}_1, \overline{\Gamma}_2 \vert \Omega_1, \Omega_2 \vdash \mu_1 \odot \mu_2 : (P_1 \odot P_2)(s_0, s_2)}


\inferrule*
  {\overline{\Gamma} \vert \Omega \vdash \epsilon : (P_1 \odot P_2) (s_0, s_2) \\ \overline{\Gamma}_L, x_0 : X_0, x_1 : X_1, x_2 : X_2, \overline{\Gamma}_R \vert \Omega_L, p_1 : P_1(x_0, x_1), p_2 : P_2(x_1, x_2), \Omega_R \vdash \mu : Q(t_0, t_1)}
  {\overline{\Gamma}_L, \overline{\Gamma}, \overline{\Gamma}_R \vert \Omega_L, \Omega, \Omega_R \vdash \text{let } (p_1 : P_1(x_0, x_1), p_2 : P_2(x_1, x_2) = \epsilon) \text{ in } \mu : Q(t_0[s_0/x_0], t_1[s_2/x_2])}

ModalTT

VDC Semantics

We define a modal, fibrational VDC (with composites) \([\![ \mathbb{T}_\Sigma ]\!]\) as follows:

  • Objects are term contexts \(\Gamma = (x : X)\) (these are effectively just types annotated with a variable).
  • Tight morphisms \((x : X) \to (y : Y)\) are terms \((x : X) \vdash s : Y.\)
  • Proarrows \((x : X) \nrightarrow (y : Y)\) are protypes \[ (x : X) ; (y : Y) \vdash P(s, t). \]

ModalTT

VDC Semantics

  • Cells

are proterms \[ \begin{aligned} \Gamma_0, \dots, \Gamma_n \vert p_1 : P_1(s_0, s_1), \dots, p_n : P_n(s_{n-1}, s_n) \vdash\\ \mu : Q(t_0[f_0(s_0)/y_0], t_n[f_n(s_n)/y_n]). \end{aligned} \]

ModalTT

VDC Semantics

  • Restriction cells are obtained via term substitution: \[ x_0 : X_0, x_1 : X_1 \vert p : P(f_0(x_0), f_1(x_1)) \vdash p : P(f_0(x_0), f_1(x_1)) \]
  • Loose composition is precisely \(\odot\)-introduction on protypes and proterms, with the universal property supplied by \(\odot\)-elimination along with the \(\beta\)/\(\eta\)-computation rules (not shown).
  • Each modality symbol \(L \in \mathcal{M}_\Sigma\) corresponds to a monad on \([\![\mathbb{T}_\Sigma]\!]\) via the derived form \(L[-]\) and the primitive structure morphisms/cells \(\eta\) and \(\mu\). Functoriality is immediate from the normal form.

Future work

  • Typing judgments for loose units are subtle and not fully developed (hence their omission). As currently implemented, they lack a normal form.
  • The expected metatheorems (cut elimination, soundness of the VDC semantics, etc.) need to be proven more carefully.
  • The surface syntax is cumbersome and not especially user-friendly.
  • The internal representation still needs to be hooked up to CatColab so that the DSL can actually be used alongside DoubleTT models.
